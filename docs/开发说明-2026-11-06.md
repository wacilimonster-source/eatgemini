## 快速上手

### 长上下文设置（0.1.2）

默认不限制请求体、非流式响应缓冲大小、SSE 单事件大小与总生成时长；
未提供输出长度时使用目标模型的最大输出额度（当前六个内置模型为 65,536 tokens）。
客户端指定的较小 `max_tokens` / `max_completion_tokens` 与 `stop` 仍生效。
网关不裁剪历史消息；模型硬上限、客户端历史裁剪与 Google 额度仍生效。
首事件等待 10 分钟，流空闲等待 5 分钟。

升级已有数据目录时，先退出旧版，再运行：

```powershell
.tools/dart-sdk/bin/dart.exe run tool/open_context_limits.dart
```

脚本备份旧配置，将 `compatibility.*.defaultMaxOutputTokens` 与
`policy.maxRequestBytes`、`policy.maxBufferedResponseBytes`、`policy.requestDeadlineMs`
设为 `0`，并补齐内置模型缺失的输入/输出上限。随后启动新版。
“模型与额度”页面按模型展示输入上下文与最大输出，未知上限显示“未知”。

```powershell
# 依赖 Dart SDK 3.x；本仓库自带一份在 .tools/dart-sdk（已 gitignore）
powershell -ExecutionPolicy Bypass -File tool/build.ps1 -Version 0.2.9
# 产物：build/eatgemini.exe                 便携版（GUI 子系统）
#       build/eatgemini-v0.2.9.exe          发布用便携版副本
#       build/eatgemini-setup-v0.2.9.exe    安装版（尾部内嵌便携版 exe）
#       build/update.json                   更新检查回退源
# 只要便携版：加 -SkipInstaller
```

安装版参数：`--silent`（无弹窗）、`--install-dir <路径>`、`--no-launch`、
`--autostart`、`--uninstall`（卸载，保留数据目录）、`--data-dir <路径>`。
升级时安装器通过 `instance.json` 里的 `consolePort`/`ipcNonce` 调 `/ipc/quit`
请求旧实例优雅退出，再替换 exe。

开发期运行：

```bash
.dart_sdk 里的 dart run bin/eatgemini.dart --data-dir <目录> --console
```

- `--data-dir`：数据目录覆盖（默认 `%LOCALAPPDATA%\eatgemini`）。
- `--no-window` / `--minimized`：启动时不打开监控窗口。
- `--console`：开发时回显日志。
- `--version --version-out <file>`：构建校验用。

## 与设计文档的偏差（有意为之，均已在代码注释说明）

1. **托盘已实现（F12/§14，2026-11-07）**：`lib/src/desktop/tray_isolate.dart`（win32 message-only 窗口 + Shell_NotifyIconW）、`tray_glyph.dart`（纯 Dart 光栅化宝石图标与 ICO/DIB，按系统小图标尺寸选帧）、`tray_coordinator.dart`（主 isolate 侧：状态推送、命令回传、SSE 全断 5s 的关窗检测与一次性气泡）。菜单：打开监控 / 复制网关地址 / 状态（只读）/ 退出；图标颜色随状态 绿=ready、黄=needs_key/degraded、红=错误、灰=其他；`TaskbarCreated` 处理 Explorer 重启。托盘右键菜单交互与气泡属真机行为，自动化只验证到 NIM_ADD 成功与优雅退出（探针脚本已实测）。
2. **关窗检测改用 detachSocket 原生 socket（2026-11-07 真机修复）**：Windows 上客户端断开后 `HttpResponse` 的写入会静默成功、`res.done` 永不完成（实测断开后 ping 十几分钟无错误），SSE 计数永不回落 → 关窗检测从未触发过（`closeHintShown` 一直为 false）。`ConsoleServer._handleEvents` 现在发完头帧后 `detachSocket`，改在原生 socket 上写 SSE：onDone/onError 可靠感知断连（FIN/RST 均触发，回归测试 `test/console_sse_lifecycle_test.dart`）。两个坑：detach 前必须关 chunked（否则客户端按 chunked 解析裸字节）；原生 IOSink 在内部 addStream 未完成时调 `flush()` 会抛 "StreamSink is bound to a stream"（竞态），只 write 不 flush。另：托盘左键单击即打开窗口（双击防抖合并），首次关窗气泡文案明确指向托盘折叠区。监控窗口的任务栏图标曾用独立 favicon.svg（蓝色渐变、比例不同、小尺寸发糊），现改由 tray_glyph 同一光栅化器构建期生成 favicon.ico（ready 绿档）内嵌下发，托盘与任务栏同几何同色。两轮真机实测后的最终结论：favicon.ico 只含 40/48/64 大帧——提取 Edge 窗口 HICON 逐帧比对发现，Edge 生成窗口图标时固定拿 ICO 最小帧放大到 SM_CXICON 物理尺寸（16px 被放大 2.5 倍是发糊根源）；且 Chromium 把 favicon 强制缩到 16/32 存储，favicon 管线的上限就是 32px 位图。最终解法：tray_isolate 周期性（2s）对标题为「eatgemini 监控」的窗口 WM_SETICON 覆盖为 ICON_BIG=48 帧 / ICON_SMALL=24 帧的精确位图（提取 HICON 复验 MAD=0.000，即逐像素一致）；宝石占比加大 15→19/26、圆角收紧 8→6.5/26 提升小尺寸可读性；托盘帧位补 24。
3. **太平洋重置时钟为手写实现**（`lib/src/core/pacific_clock.dart`）：只支持 America/Los_Angeles，按 2007 年起的美国联邦夏令时规则计算，单测覆盖了切换日与午夜偏移。没有引入 `timezone` 数据包，避免单文件体积与数据初始化。
4. **upstream.baseUrl 允许本机回环 http**（仅 127.0.0.1/localhost/::1），供本地代理与测试；其他主机强制 https。出站白名单（EgressGuard）同步放行回环。
5. **listen.port 支持 0**（系统随机端口），供测试与冒烟；界面不提供该选项。
6. **代理 `system` 模式**当前等同"环境变量"（读取 WinINET 属 M2），设置页有说明。
7. **准入排队**做了简化实现：全局/每客户端并发上限 + 有限等待，超出即 429；没有独立 FIFO 轮转队列。
8. **安装包 / 自动更新 / 开机自启已落地（2026-11-10，原属 M2）**：安装版是纯 Dart 自解压 exe（尾部附加便携版 exe 作为 overlay payload，PE 加载器忽略节表外数据，实测追加后仍可运行），不引入 Inno Setup/NSIS；安装到 `%LOCALAPPDATA%\Programs\eatgemini`，写 HKCU 卸载项与开始菜单快捷方式，卸载保留数据目录。开机自启写 HKCU Run（默认关闭、启动自愈路径）。更新检查改为**默认不联网**：手动点击或显式开启自动检查（24h 节流）才访问 GitHub，界面无外链，发布校验的外链白名单同步放行 `api.github.com` / `raw.githubusercontent.com`；这修订了设计文档 §7 N2「不存在更新检查」的原约束，隐私边界改为「只取版本元数据、不含任何凭证或对话」。托盘菜单新增「检查更新」「开机自启（可勾选）」。

9. **托盘点击卡顿修复（2026-11-10 晚）**：托盘 isolate 原每 2 秒用 `EnumWindows + GetWindowText` 遍历所有顶层窗口（对其他进程发**同步** WM_GETTEXT），再用 `SendMessage` 给 Edge 窗口下发 WM_SETICON；任一窗口繁忙就会阻塞 `GetMessage` 循环，托盘点击排不上队。改为 `FindWindowEx`（窗口管理器内核侧按标题匹配，不发跨进程消息）+ `PostMessage`（异步下发，不等 Edge 响应）。另在 `openWindow()` 加快速路径：已有 SSE 连接时用 `window_activator.dart` 前置现有窗口，不再无条件冷启动 Edge；`TrayStateCache` 让每 2 秒的状态推送在值不变时跳过，减少托盘 IPC 与 NIM_MODIFY。

10. **托盘快速前置回归修复（v0.2.8）**：v0.2.7 的 `openWindow()` 快速路径里，后台进程调用 `SetForegroundWindow` 被 Windows 前台锁定静默拒绝，但函数仍返回 true → 直接 return、不再启动浏览器，托盘点击变成「完全没反应」（模拟托盘消息可复现，日志只有「已前置现有监控窗口」）。修复：`window_activator.dart` 用 `HWND_TOPMOST → HWND_NOTOPMOST` 强制把窗口带到可见最前（不需要前台权限），配合 `AttachThreadInput` 提高抢前台成功率；`FindWindowEx` 循环加 32 次上限与句柄去重防止卡死；`TrayCoordinator.pulse()` 恢复每 2 秒轻量心跳，弥补状态推送去重后托盘 isolate 事件循环不再被唤醒的隐含契约；托盘 action 转发加日志便于诊断。另加「前台确认」：只有 `GetForegroundWindow()` 确认目标窗口真正成为前台才算快速路径成功，否则回退 `browser.open()` 启动浏览器，保证点击一定有反馈。

11. **托盘点击「没反应」终局修复（v0.2.9）**：模拟托盘消息与日志证明点击一直正常送达，问题在开窗方式——专用 profile `%LOCALAPPDATA%\eatgemini\webview` 被驻留的 Edge 主进程占用（实测 10 个相关进程，主进程仍带旧票据 `--app=`），监控窗口早已不存在；此后 `--app=` 请求全被驻留实例吞掉，`Process.start` 却仍报成功，窗口根本不创建。改为 `BrowserLauncher.openVisible()` 用 `ShellExecute`（由 explorer 处理、不闪控制台窗口）打开控制台 URL；`activateMonitorWindow()` 放宽为「找到窗口并用 TOPMOST 置顶可见」即算成功，避免误判成无窗口而重复开标签。代价是监控页改用默认浏览器标签而非 Edge 应用模式窗口，页面功能不变。

## 已知的引擎行为细节（接手前必读）

- `_Reject`（本地拒绝）不会消耗上游请求；`/v1/models`、`/router/status`、`/healthz` 永不生成文本。
- 流式提交边界：上游 200 + 第一个 choices 非空的 SSE 事件（含 role-only）才提交；之后断流会发 `error` 帧而不是补 `[DONE]`。
- `releaseUnsent` 目前只在极端路径使用；已发送但超时/取消的请求按 `uncertain` 保留配额计数（内核文档 §9.1）。
- Dart `HttpClient` 的连接取消：响应已完整消费时不再中断连接（SDK 的 `_returnConnection` 在 detach 后会崩，见 transport.dart 注释）。
- win32 5.x 不导出 `CreateMutex`，单实例改用数据目录独占文件锁（app_env.dart 注释）。

### 有意偏差（相对设计规范）

1. **引导完成标记存 localStorage** 而非 `config.json.onboardingDone`：避免配置解析器对新增字段的兼容风险；控制台只有一个 webview，无跨浏览器共享问题。
2. **事件环与一小时图为客户端内存**：重启即清（规范 §八 D41 本就要求事件不落盘）；服务端事件环（F07）与每日用量持久化（F08）仍按 W2 计划。
3. **TPM 列与 Token 用量列未展示**：`/api/models` 无输入 TPM 数据、请求记录无 usage 字段——诚实不展示，待后端补数据源（F03/F04 的后端增量）。
4. **二维码（F11）、端到端测试消息（F09）、安全卡（F06）、通知（F13）未实现**：分别需要自研 QR 编码、新 API、鉴权锁定暴露、win32 toast——按里程碑 W3 待办；接入页二维码按钮暂以 toast 说明。托盘（F12）已于 2026-11-07 实现（见与设计文档的偏差 §1）。
